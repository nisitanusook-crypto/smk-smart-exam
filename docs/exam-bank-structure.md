# โครงสร้างคลังข้อสอบ O-NET (ม.3 / ม.6)

เอกสารนี้อธิบายโครงสร้างข้อมูลคลังข้อสอบที่เตรียมไว้ใน Phase 1 และกติกาการนำเข้าข้อสอบในระยะถัดไป

## 1. หลักการ (ข้อบังคับ)

| ข้อ | หลักการ |
| --- | --- |
| 1 | รองรับเฉพาะ **O-NET ม.3 และ ม.6** — ระบบไม่มีโครงสร้างสำหรับ V-NET (`GradeLevel` มีแค่ `M3`, `M6`) |
| 2 | ใช้เฉพาะ **ข้อสอบจริงย้อนหลังไม่เกิน 20 ปีการศึกษา** API ปฏิเสธปีที่อยู่นอกช่วงนั้น |
| 3 | **ห้ามใช้ AI สร้างข้อสอบหรือเฉลย** ทุกข้อต้องถอดความตรงจากเอกสารต้นฉบับ |
| 4 | ทุกชุด/ทุกข้อต้องอ้างอิง `ExamSource` (ลิงก์หรือไฟล์ต้นฉบับ) ที่ตรวจสอบย้อนกลับได้ |
| 5 | ข้อสอบจะแสดงให้นักเรียนได้ก็ต่อเมื่อ `verificationStatus = VERIFIED` **และ** `isPublished = true` |
| 6 | เฉลยเก็บแยกตาราง `AnswerKey` และต้องระบุ `sourceRef` (เอกสารเฉลยอย่างเป็นทางการ) |

## 2. แผนภาพความสัมพันธ์

```
Subject (วิชา × ระดับชั้น)
  └─ ExamPaper (1 ชุด = วิชา × ปีการศึกษา) ──► ExamSource (ต้นฉบับข้อสอบ)
        │                                  └► ExamSource (ต้นฉบับเฉลย, ถ้าแยกไฟล์)
        ├─ ExamSection (ตอนที่ 1, 2, ...)
        └─ Question (ข้อที่ n ตามต้นฉบับ) ──► ExamSource + sourcePage
              ├─ Passage (บทอ่าน/สถานการณ์ที่ใช้ร่วมกัน)
              ├─ Choice[] (ตัวเลือกตามต้นฉบับ)
              ├─ AnswerKey (เฉลย + sourceRef)
              └─ QuestionTopic ──► Topic (สาระ/ตัวชี้วัด สำหรับวิเคราะห์ผล)

ExamAttempt (การสอบ 1 ครั้ง: PRACTICE / SIMULATION)
  └─ AttemptAnswer (คำตอบรายข้อ, ทำเครื่องหมายทบทวน)
```

## 3. สถานะการตรวจสอบ (`VerificationStatus`)

```
DRAFT ──► PENDING_REVIEW ──► VERIFIED ──► (เผยแพร่ isPublished = true)
                        └──► REJECTED
```

- `DRAFT` — กำลังถอดความจากต้นฉบับ
- `PENDING_REVIEW` — รอผู้ตรวจสอบเทียบกับต้นฉบับ
- `VERIFIED` — ผู้ดูแลระบบยืนยันแล้ว (บันทึก `verifiedById`, `verifiedAt`)
- `REJECTED` — อ้างอิงไม่ได้/ไม่ตรงต้นฉบับ

## 4. รูปแบบข้อสอบที่รองรับ (`QuestionType`)

| ค่า | ความหมาย | ตัวอย่างรูปแบบ `AnswerKey.correctAnswer` |
| --- | --- | --- |
| `SINGLE_CHOICE` | ปรนัยเลือก 1 คำตอบ | `{ "labels": ["3"] }` |
| `MULTIPLE_RESPONSE` | เลือกได้หลายคำตอบ | `{ "labels": ["1", "4"] }` |
| `PAIRED_CHOICE` | ปรนัยเชิงซ้อน (หลายข้อย่อย) | `{ "parts": { "a": "1", "b": "2" } }` |
| `NUMERIC_ANSWER` | ระบายตัวเลข/เติมคำตอบตัวเลข | `{ "numeric": "12.5" }` |
| `MATCHING` | จับคู่ | `{ "pairs": { "1": "ค", "2": "ก" } }` |

> รูปแบบ JSON ของเฉลยจะถูกกำหนดเป็น schema อย่างเป็นทางการพร้อมเครื่องมือนำเข้าใน Phase ถัดไป

## 5. รายวิชาที่ seed ไว้

ทั้ง ม.3 และ ม.6 มีรหัสวิชา `TH` `MA` `SC` `EN` `SO` `HE` `AR` `CT`
(วิชาที่ไม่ได้สอบในปัจจุบันถูกตั้ง `isActive = false` เพื่อเก็บข้อสอบย้อนหลังของปีที่เคยสอบ)

**ผู้ดูแลระบบควรตรวจสอบสถานะ `isActive` ของแต่ละวิชากับประกาศของ สทศ. ก่อนใช้งานจริง**
เพราะรายวิชาที่สอบ O-NET แต่ละปีเปลี่ยนแปลงตามประกาศ

## 6. API ที่พร้อมใช้งานใน Phase 1

| Method | Path | สิทธิ์ | คำอธิบาย |
| --- | --- | --- | --- |
| GET | `/api/exam-bank/overview` | ทุกบทบาท | ภาพรวมคลังข้อสอบตามระดับชั้น/วิชา/ปี (นักเรียนเห็นเฉพาะชุดที่เผยแพร่) |
| GET | `/api/exam-bank/subjects` | ทุกบทบาท | รายวิชา (`?gradeLevel=M3`) |
| GET | `/api/exam-bank/papers` | ทุกบทบาท | รายการชุดข้อสอบ (`?gradeLevel=&subjectId=&academicYear=`) |
| POST | `/api/exam-bank/papers` | ADMIN, TEACHER | ลงทะเบียนชุดข้อสอบ (ต้องมี `sourceId`, ปีอยู่ในช่วง 20 ปี) |
| GET | `/api/exam-bank/sources` | ADMIN, TEACHER | รายการเอกสารต้นฉบับ |
| POST | `/api/exam-bank/sources` | ADMIN, TEACHER | เพิ่มเอกสารต้นฉบับ (ต้องมี `url` หรือ `fileUrl`) |
| POST | `/api/exam-bank/sources/:id/verify` | ADMIN | ยืนยัน/ปฏิเสธเอกสารต้นฉบับ |
